# OpenClasp logo pack

Hook-lock mark + wordmark. Accent `#f04b2d`. Dark `#0c0a0a`. Light `#f7f4f2`.

## What to upload

| Use                                 | File                                                                        |
| ----------------------------------- | --------------------------------------------------------------------------- |
| SVG mark (best default)             | `svg/clasp-mark.svg`                                                        |
| App / Discord / Slack / GitHub icon | `png/clasp-icon-dark-512.png` or `1024`                                     |
| Apple touch / PWA                   | `png/clasp-icon-dark-180.png` / `192`                                       |
| Transparent mark on light           | `png/clasp-mark-512.png` or `svg/clasp-mark.svg`                            |
| Transparent mark on dark            | `svg/clasp-mark-white.svg` or `png/clasp-mark-white-512.png`                |
| Header / docs lockup                | `svg/clasp-wordmark.svg` (light bg) or `clasp-wordmark-white.svg` (dark bg) |
| Favicon                             | `favicon.ico` or `svg/clasp-mark.svg`                                       |

Keep the mark square. Do not add a circle, drop shadow, or extra box around it.
